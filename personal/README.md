# GymLog Personal

A separate personal training journal with editable routines, workout logging, rest timers, history, body-weight trends, and personal records.

Serve this folder with a static web server or deploy it to Cloudflare as static assets. No build step is required.

Records stay in this browser. Export and restore JSON backups to move them between devices. There is no cloud sync or account login.

The legacy GymLog app and the fitness-platform deployment are separate.
